# JerBite: Modern Food Ordering & Delivery Platform (Frontend)

React + Tailwind CSS (Vite, `.jsx`) frontend application for JerBite.

* **Backend API Repository:** [https://github.com/mummyslovelyson/JerBite-Backend](https://github.com/mummyslovelyson/JerBite-Backend)

---

## Portals & Access Points

* **JerBite Customer Storefront:** [http://localhost:5173/](http://localhost:5173/)
  - Dynamic discovery: search, category filtering, featured approved kitchens, popular food add-to-cart, active promotions, and customer cart preservation.
* **Customer Authentication:** [http://localhost:5173/login](http://localhost:5173/login) & [http://localhost:5173/register](http://localhost:5173/register)
* **Restaurant Partner Portal:** [http://localhost:5173/manager/login](http://localhost:5173/manager/login) & [http://localhost:5173/manager/register](http://localhost:5173/manager/register)
* **Delivery Fleet Portal:** [http://localhost:5173/rider/login](http://localhost:5173/rider/login) & [http://localhost:5173/rider/register](http://localhost:5173/rider/register)
* **Dedicated Admin Portal:** [http://localhost:5173/admin/login](http://localhost:5173/admin/login)

---

## Quick Start (Frontend)

```bash
cd frontend
npm install
npm run dev
# Vite runs at http://localhost:5173
```

To build for production:
```bash
npm run build
```

---

## Dedicated Dashboards

1. **JerBite Admin Console:** 12 management modules & 75 dedicated pages for overview, restaurants, customers, food, riders, orders, payments, notifications, support, analytics, and settings.
2. **Restaurant Manager Kitchen Dashboard:** Live KDS order dispatch, menu items, categories, schedules, delivery tracking, finances, promotions, and reports.
3. **Delivery Rider Fleet:** Available delivery gigs, active orders, route navigation, and payout history.
